## 一、功能描述

用户选择源表格文件（`.xls` / `.xlsx` / `.csv`）中的单个 Sheet，选择或创建**模板**（模板定义新表格的列结构，持久化于 `<应用目录>/template/`），系统按「模板列 + 内置列别名」自动匹配源表列并允许手动调整，将源数据按映射填入模板结构，生成新表格。

导出格式：**xlsx / xls / csv / vcf / txt**（由用户在导出时选择）。

关键行为：

- 模板系统为公共基础设施（`core/template/`），本功能是其首个使用方；后续新功能可无缝复用
- 内置列（姓名 / 手机 / 公司名 / 网址）可增删改查并持久化
- 手机号校验、标红、姓名合并等处理规则由**全局设置界面**控制（默认：校验开、标红开、合并关）
- vcf 导出字段由全局设置指定（默认 姓名/手机/公司名/网址），**映射到的字段才导出**，且预览中可见

## 二、全局设置项（定义于 `docs/template_system.md` 第四节）

| 设置键 | 默认值 | 对本功能的影响 |
|--------|--------|---------------|
| `phone_validate` | `true` | 是否校验手机号合法性（影响预览标红与统计） |
| `phone_highlight` | `true` | 非法手机号单元格是否标红（xlsx/xls 输出与预览） |
| `phone_merge` | `false` | 同一姓名多手机号时，姓名单元格跨行合并（仅 xlsx/xls） |
| `phone_separators` | 字符串列表 | 见默认值 | 同一姓名多手机号的分隔符（逗号/中文逗号/分号/中文分号/顿号/空格/换行/竖线），用于拆分；未勾选合并时每个手机号单独一行、相同内容不合并 |
| `csv_encoding` | `utf-8-bom` | csv 输出编码 |
| `txt_encoding` | `utf-8-bom` | txt 输出编码（默认带 BOM，Windows 记事本友好） |
| `txt_separator` | `" "` | txt 行内分隔符 |
| `vcf_fields` | 四字段全选 | vcf 导出包含字段（内置列 key 列表） |
| `vcf_name_prefix` | `vcf_` | vcf 姓名前缀（纯文本；配合时间戳形成 `vcf_20260808张三`） |
| `vcf_name_suffix` | `""` | vcf 姓名后缀 |
| `vcf_timestamp` | `true` | 是否在 vcf 姓名上附加年月日时间戳（`YYYYMMDD`）；预览与导出一致 |
| `vcf_timestamp_position` | `prefix` | 时间戳位置：`prefix`=姓名前 / `suffix`=姓名后 |
| `declaration_detect` | `true` | 声明行检测（详见步骤 3；旧版 qcc_declaration_skip 自动迁移） |
| `declaration_keywords` | 多平台词表 | 声明关键词（逗号分隔可编辑），任一单元格命中即视为声明行 |
| `log_debug` | `false` | 详细日志开关：AOP 日志（DEBUG）输出，排查用（详见 `CLAUDE-detailed.md` 第五节） |

设置界面为**全局入口**（主窗口），所有功能共享同一份 `settings.json`。

## 三、数据模型

本功能新增 dataclass（权威定义见 `CLAUDE-detailed.md`）：

```python
@dataclass
class MappingConfig:
    template: Template                 # 选中的模板（core/template/config.py）

class ExportRow:
    values: List[str]                  # 与模板 enabled 列一一对应的值列表

```

## 四、完整业务流程

### 步骤 1：选择源文件

- **模块**：`panel.py`（复用 `ui/components/file_picker.py`）
- **过滤**：`.xls` `.xlsx` `.csv`
- 取消选择 → 无操作

### 步骤 2：选择 Sheet

- `.xls/.xlsx` 显示 Sheet 下拉框（默认第一个）；`.csv` 无 Sheet 概念，跳过此步
- 失败：`FileReadError` → panel 捕获 → 弹窗 + ERROR 日志 → 终止

### 步骤 3：读取源数据（含企查查声明行检测）

- **模块**：`core/file_io/` → `SheetData`（headers + rows）
- 新增 `.csv` 读取支持（`CsvReader`，编码自动探测：UTF-8 BOM → UTF-8 → GBK）
- **声明行检测**（`declaration_detect=true` 时执行，防误判优先）：
  1. 规则一（空行）：首行全空 → 视为前导空行跳过
  2. 规则二（结构）：首行仅 1 个非空单元格且第二行非空单元格数 ≥ 2 → 判定为声明行（不依赖关键词）
  3. 规则三（单格关键词）：首行仅 1 个非空单元格且内容命中 `declaration_keywords` → 判定为声明行
  4. **多格行（≥2 个非空单元格）不判定为声明行**（避免正常表头含「声明/数据来源」等词被误判）
  5. 命中 → 以**第二行为表头**、第三行起为数据行，记录 `declaration_skipped=True`；声明行后如有空行一并跳过
  6. 未命中 → 第一行即表头，正常处理
- 检测结果返回给 `panel.py`，用于用户提示（见 UI 行为规格）

### 步骤 4：选择 / 管理模板

- **模块**：`panel.py` + `core/template/manager.py`
- 展示模板列表（`TemplateManager.list_templates()`，按名称排序）
- 操作：应用、新建（手动 / 从表格导入）、复制、重命名、删除、列编辑（详见模板系统设计文档）
- 无模板时提示用户先创建（提供「从当前源文件表头一键生成模板」快捷入口）

### 步骤 5：应用模板（自动匹配）

- **模块**：`core/template/matcher.py`（纯函数）
- 输出：`List[ColumnMatch]`（每个模板列对应 exact / alias / none 状态）
- 未匹配（none）列：UI 标黄，需用户手动指定或置空
- 应用成功后**直接进入步骤③预览与导出**（模板已保存映射，无需再调整；想改映射可点上一步回②）

### 步骤 6：手动调整映射

- **模块**：`panel.py`
- 映射编辑表格：每行 = 一个模板 enabled 列，列 = [模板列名 | 匹配状态 | 源列下拉框（含「（不映射）」）]
- 手动选择后状态标记为 manual
- 校验：若模板列未映射（=「不映射」），导出时该列全部留空，不报错

### 步骤 7：生成预览

- **模块**：`processor.py`（纯函数）
- 转换规则见第五节
- 预览**所见即所得**：xlsx/xls 以表格展示（列标题 = 模板 enabled 列名）；csv/txt/vcf 以**文本形式**展示导出文件的真实内容（vcf 含姓名前后缀与时间戳效果）
- 汇总文案：`共 {N} 行`；vcf 时追加 `，vcf 姓名前缀：{生效前缀}`；启用了校验且存在异常时追加 `，其中 {M} 个手机号格式异常`

### 步骤 8：选择导出格式与路径

- **模块**：`panel.py`
- 格式下拉：xlsx / xls / csv / vcf / txt（默认 **vcf**）
- 保存对话框：默认文件名 `源名_<yyyyMMddHHmmss>.<扩展名>`（用户可改），默认目录为源文件所在目录
- 用户可改扩展名（以对话框最终路径扩展名为准，格式下拉与扩展名不一致时以扩展名为准并提示）

### 步骤 9：写入文件

- **模块**：`core/file_io/`（按扩展名选择 writer）
- 失败：`FileWriteError` → panel 捕获 → 弹窗 + ERROR 日志 → 终止

### 步骤 10：成功提示

- 内容：`导出成功，共 {N} 行，文件已保存至：{路径}`
- INFO 日志 + 状态栏展示

## 五、数据转换规则（`processor.py`，纯函数）

### 手机号拆分（与旧版一致，不受设置影响）

1. 取源行映射到「手机」列的源值（已转字符串）
2. 按英文分号 `;` 分割 → 每段 `strip()` → 过滤空段
3. 过滤后为空 → 生成一条 `phone=""` 的记录

### 行生成规则

- 手机号拆分出 N 段（N≥1）→ 生成 N 行（每段一行）；空 → 生成 1 行
- 每行：模板各 enabled 列按映射取值（源行对应列值 `strip()` 后填入；未映射列填 `""`；手机列填拆分后的单段值）
- **csv/txt/vcf**：无合并概念，每行均为完整记录（姓名等字段每行重复填充）
- **xlsx/xls**：`phone_merge=true` 时，同一姓名（跨行同名也合并）的行按首次出现顺序分组，姓名列跨行合并单元格（合并行数 = 组行数，非首行姓名置空）；`phone_merge=false` 时姓名每行重复填充，不做合并

### 手机号校验（`phone_validate=true` 时生效）

沿用旧规则：

| 规则 | 条件 |
|------|------|
| 跳过校验 | 以 `+` 开头 → 合法 |
| 合法 | 11 位全数字，第 1 位 `1`，第 2 位在 `3-9` |
| 空手机号 | 恒合法，不计入异常统计 |

- `phone_valid=False` 的行：预览标红；xlsx/xls 输出标红（`phone_highlight=true` 时）
- 异常统计文案：`第 {source_row_index} 行：{phone} 不是合法手机号`

### 手机号列的识别

校验与拆分仅作用于**映射到内置列 key=`phone` 的模板列**；模板中不存在映射到 `phone` 的列时，跳过校验与拆分（每源行生成 1 行，原样填充）。

## 六、导出格式规格

### xlsx / xls

| 项目 | 规格 |
|------|------|
| 表头 | 模板 enabled 列名（按模板列顺序） |
| 数据 | 按映射填充；拆分/合并规则见第五节 |
| 样式 | `phone_valid=False` 且 `phone_highlight=true` 的手机单元格红色背景 `#FF0000` |
| 合并 | `phone_merge=true` 时按姓名分组（跨行同名合并，空姓名行不参与），姓名列跨行合并（仅当映射到 `phone` 的列存在） |

### csv

| 项目 | 规格 |
|------|------|
| 表头 | 模板 enabled 列名 |
| 分隔符 | 逗号 `,`（标准 CSV，含引号转义） |
| 编码 | 按 `csv_encoding`：`utf-8-bom`（UTF-8 带 BOM）/ `utf-8` / `gbk` / `utf-16`（UTF-16 LE 带 BOM）/ `unicode`（同 utf-16） |
| 换行 | `\r\n` |

### vcf（vCard 3.0）

| 项目 | 规格 |
|------|------|
| 记录粒度 | 一个手机号一条 vCard（与 xlsx 行数一致）；每 vCard 的字段 = 全局设置 `vcf_fields` 中**已映射**的内置列字段 |
| FN | `vcf_fields` 含 `name` 且已映射 → `FN:{值}`（缺省时省略 FN）；**同一姓名多个手机号时，姓名追加 `_1`、`_2`…序号**（按组内顺序从 1 累加；单手机号不加；合并开启时被置空的姓名恢复组首姓名再编号） |
| TEL | `vcf_fields` 含 `phone` 且已映射 → `TEL;TYPE=CELL:{值}` |
| ORG | `vcf_fields` 含 `company` 且已映射 → `ORG:{值}` |
| URL | `vcf_fields` 含 `website` 且已映射 → `URL:{值}` |
| 编码 | UTF-8；`\n` 换行；vCard 之间空一行 |
| 结构 | `BEGIN:VCARD` / `VERSION:3.0` / 字段 / `END:VCARD` |

> 仅 `vcf_fields` 列出的内置列参与 vcf 导出；模板中未映射的字段不导出。自定义内置列（非四个默认 key）不在 `vcf_fields` 可选范围内（v1 限制，见「不在范围内」）。

### txt

| 项目 | 规格 |
|------|------|
| 内容 | **首行为表头**（模板 enabled 列名，用 `txt_separator` 连接）；数据行 = 每源记录一行（拆分后每手机号一行），行内各列值用 `txt_separator` 连接，顺序 = 模板列顺序 |
| 编码 | UTF-8 |
| 换行 | `\n` |

## 八、边界情况处理表

| 场景 | 处理方式 |
|------|---------|
| 模板目录为空（无模板） | 不阻断：自动使用**内置列默认映射**（目标列 = 内置列 label，key = 内置列 key）正常进入映射对比与导出；模板下拉首项固定「（默认映射：内置列）」，状态栏提示可新建/导入模板 |
| 企查查/天眼查等导出文件（首行为声明） | `declaration_detect=true` 时自动跳过（结构或关键词命中）并提示；`false` 时第一行视为表头原样处理 |
| 声明关键词自定义 | 设置界面「文件处理」分组可增删关键词（逗号分隔），覆盖更多导出平台 |
| 第一行仅 1 个非空单元格但实为表头（单列表格） | 规则二误判风险：单列表格首行非空=1、第二行非空=1（<2），不会误判；若第二行也仅 1 列非空则无法满足「≥2」条件，安全 |
| 声明行检测开启但未命中 | 正常处理，不做任何提示之外的打扰 |
| 模板某列未映射 | 该列导出时全为空字符串，不报错 |
| 源表只有表头无数据 | 预览提示「未找到可导出的数据」，不进入导出 |
| 源行手机号为空 | 生成 1 行 `phone=""`，合法，不标红 |
| 手机号含 `+` 前缀（如 `+86138...`） | 不校验，原样导出 |
| 手机号列不存在映射 | 不拆分、不校验，每源行 1 行原样导出 |
| 同名模板 | 展示名相同可共存（文件名自动加序号） |
| 模板名含非法字符 | 文件名替换为 `_`，展示名不变 |
| csv 源文件编码未知 | 按 BOM → UTF-8 → GBK 顺序探测，全部失败抛 `FileReadError` |
| 导出扩展名与格式下拉不一致 | 以对话框最终扩展名为准并提示 |
| 同一源列被多模板列匹配 | 先匹配者占用，后者继续找下一个源列 |

## 九、不在本功能范围内（禁止自行实现）

- 不做模糊列名匹配（包含/相似度/拼音）——v1 仅完全相等匹配
- 不对数据去重、排序
- 不修改源文件
- 不支持多 Sheet / 多模板同时导出（单 Sheet + 单模板）
- vcf 不支持自定义内置列字段导出（仅四个默认字段，v1）
- 不连接任何网络服务
